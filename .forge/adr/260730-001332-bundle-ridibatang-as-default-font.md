# 리디바탕을 앱에 번들해 기본 본문 글꼴로 쓴다

`src/fonts.ts`는 "엄선 후보 + 런타임 가용성 필터"만 쓰고 웹폰트는 번들하지 않는다는 원칙을 명시적으로 담고 있었다("웹폰트 번들은 8.5MB 앱을 부풀려 경량 원칙과 충돌한다"). 리디바탕을 **기본** 본문 글꼴로 만들려면 이 원칙을 이 폰트 하나에 대해 뒤집어야 한다 — 기본값이 설치 여부에 따라 조용히 폴백되면 애초에 기본값이 아니고, 배포 대상이 "나와 내 다른 맥"이므로 맥마다 폰트를 손으로 설치해야 하는 기본값은 신뢰할 수 없다.

계측해 보니 원칙의 근거가 이 폰트에는 거의 적용되지 않았다. woff2 변환본이 **457,548 B (447 KiB)** 로, 한글 음절을 **11,172/11,172 전부** 담고 ASCII·Latin-1 도 완전하다(한자는 0). 서브셋할 이유도 없다.

라이선스는 SIL OFL 1.1 이다. 폰트 바이너리 자체는 `name` 테이블에 License(ID 13)·License URL(ID 14) 레코드가 **없고** Copyright 에 `All rights reserved` 만 있어 한 번 의심했지만, 배포처 조건은 수정·복제·배포와 프로그램 내 임베딩을 명시적으로 허용하며(유료 판매만 금지) 여러 집계처가 일치한다. 이 확인이 필요했던 이유는 **레포와 릴리스가 공개**라 번들이 사적 사용이 아니라 공개 재배포이기 때문이다.

## 고려한 대안

- **설치된 폰트 감지 (기존 방식 유지)** — `CANDIDATES` 에 한 줄 추가하면 끝이고 앱 크기 증가 0, 라이선스 노출 0 이다. 실제로 이 맥에는 이미 설치돼 있다(`~/Library/Fonts/RIDIBatang.otf`). 그러나 다른 맥에 설치하지 않으면 기본 글꼴이 조용히 폴백되어 요구를 충족하지 못한다.
- **설치 감지 + 번들 폴백 하이브리드** — 양쪽 장점을 갖지만 코드 경로가 둘로 갈리고 번들 리스크는 그대로 남는다. 단독 사용자용 앱에 과설계다.
- **OTF 무변환 번들 (1.42MB)** — OFL 1.1 의 "Modified Version" 정의에 `by changing formats` 가 **명시적으로 포함**되므로, 형식을 안 바꾸면 아래의 RFN 잔여 리스크가 사라진다. 3배 크기를 감수할 만큼 실익이 크지 않다고 봤다.

## 결과

- **`fonts.ts` 의 "번들 안 함" 원칙은 이 폰트 하나에만 깨진다.** 나머지 후보는 그대로 설치 감지 방식이다 — 원칙이 사라진 게 아니라 예외가 하나 생긴 것이므로, 두 번째 폰트를 번들하려 할 때 이 ADR 을 다시 읽어야 한다.
- **`fontFamily: null` 의 의미가 "epub 자체 지정 존중" 에서 "앱 기본값(리디바탕)" 으로 뒤집힌다.** 그 대가로 **"책 자체 글꼴을 그대로 보기" 기능이 없어진다** — 선택 목록에서 `본문 기본값 유지` 항목을 제거한다. 되살리려면 sentinel 값(`"__inherit__"` 같은)이 필요해 상태 값이 3진으로 늘어난다. 지금은 개인용 뷰어에서 그 선택지를 쓸 이유가 없다고 판단해 지운다.
  - 이 의미 뒤집기의 실용적 이득: 기존 `state.json` 이 이미 `"fontFamily": null` 이라 **마이그레이션 코드 없이 곧바로 적용된다.** `Option<String>` 에서 명시적 `null` 은 `None` 으로 역직렬화되어 serde `default` 를 타지 않으므로, 기본값만 바꾸는 방식은 이 맥에서 아무 효과가 없었다. Rust 쪽 상태 스키마는 손대지 않는다.
- 공개 레포에 서드파티 폰트 바이너리가 들어간다. OFL 의 출처 표기는 의무가 아니라 권장이지만, 비용이 0 이므로 README·릴리스 노트·폰트 옆 라이선스 파일에 표기해 이행한다.
- **OFL §5 Reserved Font Name 조항에 기술적 잔여 리스크가 남는다.** 형식 변환은 OFL 상 Modified Version 이고, 리디가 RFN 을 선언했다면 변환본이 `리디바탕` 이라는 이름을 그대로 쓰는 것이 위반이다. 어느 출처도 RFN 을 언급하지 않고 배포처가 수정·배포를 허용하므로 감수한다. 문제가 되면 OTF 무변환 번들로 되돌리면 되고, 그때 앱은 1MB 커진다.
- 한자는 브라우저의 글리프 단위 폴백으로 떨어진다. 국한문 혼용 책에서 본문과 한자의 글꼴이 섞여 보일 수 있다 — 명시적 폴백 체인으로 제어하지 않기로 했으므로(실익이 거의 없다) 실제로 문제가 되면 별건으로 다룬다.
