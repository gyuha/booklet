# booklet

macOS용 개인 epub 뷰어. 파일 하나를 열어 읽는 것에만 집중하며, 장서 관리·동기화·주석 기능을 의도적으로 갖지 않는다.

## 언어

**책 (Book)**:
하나의 epub 파일. 이 프로젝트에서 책은 항상 디스크상의 파일 경로로 식별되며, 그보다 큰 묶음 단위는 존재하지 않는다.
_피할 말_: 도서, 콘텐츠, 아이템

**서재 (Library)**:
이 프로젝트에 **존재하지 않는 개념**. 여러 책을 목록으로 보여주거나 관리하는 화면은 만들지 않는다. 책은 언제나 외부(Finder, 드래그앤드롭, 열기 대화상자)에서 지정되어 들어온다.

**마지막 책 (Last book)**:
가장 최근에 연 책. 파일을 지정하지 않고 앱을 실행하면 이 책이 열린다. 목록이 아니라 단 하나만 기억한다.

**읽던 위치 (Reading position)**:
책마다 마지막으로 보던 지점. 앱이 영속적으로 보관하는 유일한 독서 데이터다.
_피할 말_: 북마크(사용자가 명시적으로 찍는 표식을 뜻하므로 다른 개념), 진도

**타이포그래피 설정 (Typography settings)**:
본문을 어떻게 보여줄지 결정하는 값 묶음 — 글꼴, 글자 크기, 줄간격, 자간, 여백. **책의 속성이 아니라 읽는 사람의 속성**이므로 [[책]]마다 따로 갖지 않고 전역으로 하나만 존재한다. [[읽던 위치]]가 책별인 것과 대비된다.
_피할 말_: 테마(색·배경까지 포함하는 더 넓은 개념이며 이 프로젝트의 비목표), 폰트 설정(글꼴만 가리켜 범위가 좁다)

**읽기 진행률 (Reading progress)**:
책 전체에서 지금 어디쯤인지를 나타내는 **비율**. **페이지 번호가 아니다** — 재유동 epub 에는 고정된 페이지 수가 없다(창 크기·글꼴·[[타이포그래피 설정]]을 바꾸면 페이지가 다시 나뉜다). 따라서 "몇 페이지 중 몇 페이지"는 이 프로젝트에서 성립하지 않는 표현이다. [[읽던 위치]]와도 다르다 — 읽던 위치는 앱이 **다시 찾아가기 위한** 정확한 지점이고, 읽기 진행률은 **사람에게 보여 주기 위한** 대략의 비율이다. 하나는 기계용, 하나는 눈용이다.
_피할 말_: 페이지 번호, 페이지 수, 쪽, 진도

**기본 본문 글꼴 (Default body font)**:
글꼴을 따로 고르지 않았을 때 본문에 적용되는 글꼴. 리디바탕이며, **선택 가능한 다른 글꼴들과 성격이 다르다** — 나머지는 시스템에 설치된 것만 목록에 나타나 있으면 쓰고 없으면 사라지는 반면, 기본 본문 글꼴은 앱 자신의 일부라 어느 맥에서든 항상 적용된다. "글꼴을 고르지 않음"은 **"책 자체 글꼴을 그대로 보기"와 같은 것이 아니며, 후자는 이 앱에 존재하지 않는 개념이다** — 본문에는 언제나 [[타이포그래피 설정]]의 글꼴이 적용된다.
_피할 말_: 폴백 글꼴(못 찾았을 때의 대체를 뜻해 방향이 반대다), 시스템 글꼴, 웹폰트

**공간 기준 이동 (Spatial move)**:
화면에서 **왼쪽/오른쪽** 페이지로 옮기는 것. 글이 오른쪽에서 왼쪽으로 흐르는 책에서는 [[읽기 순서 이동]]과 방향이 반대가 된다. 좌우 방향키와 본문 좌우 클릭이 이 기준을 쓴다.
_피할 말_: 이전/다음 페이지(읽기 순서와 구별되지 않아 이 프로젝트에서는 모호한 표현이다)

**읽기 순서 이동 (Reading-order move)**:
글이 흐르는 방향을 따라 **앞/뒤** 내용으로 옮기는 것. 책의 좌우 흐름 방향과 무관하게 언제나 다음(또는 앞) 읽을 내용에 도달한다. 위아래 방향키·스페이스·휠이 이 기준을 쓴다.
_피할 말_: 좌로/우로 넘기기(공간 방향을 뜻해 [[공간 기준 이동]]과 섞인다)

**표지 미리보기 (Cover preview)**:
Finder에서 `.epub` 파일 아이콘이 책 표지 이미지로 렌더링되는 것. **macOS가 자체 제공하는 기능이며 이 앱의 산출물이 아니다.** 이 앱에 대해서는 "깨뜨리지 않는다"는 요구사항으로만 존재한다.
_피할 말_: 썸네일 생성, 커버 추출

**뷰어 등록 (Viewer registration)**:
앱이 epub을 열 수 있다고 macOS에 선언하되, 기본 앱 자리는 가져가지 않는 상태. Finder의 "다음으로 열기" 목록에는 나타나지만 더블클릭 동작은 바꾸지 않는다.
_피할 말_: 파일 연결, 기본 앱 설정
