# booklet

macOS용 개인 epub 뷰어. 파일 하나를 열어 읽는 것에만 집중하며, 장서 관리·동기화·주석 기능을 의도적으로 갖지 않는다.

## 언어

**책 (Book)**:
하나의 epub 파일. 이 프로젝트에서 책은 항상 디스크상의 파일 경로로 식별되며, 그보다 큰 묶음 단위는 존재하지 않는다.
_피할 말_: 도서, 콘텐츠, 아이템

**서재 (Library)**:
이 프로젝트에 **존재하지 않는 개념**. 여러 책을 목록으로 보여주거나 관리하는 화면은 만들지 않는다. 책은 언제나 외부(Finder, 드래그앤드롭, 열기 대화상자)에서 지정되어 들어온다.

**마지막 책 (Last book)**:
가장 최근에 연 책. 파일을 지정하지 않고 앱을 실행하면 이 책이 열린다. 목록이 아니라 단 하나만 기억한다.

**읽던 위치 (Reading position)**:
책마다 마지막으로 보던 지점. 앱이 영속적으로 보관하는 유일한 독서 데이터다.
_피할 말_: 북마크(사용자가 명시적으로 찍는 표식을 뜻하므로 다른 개념), 진도

**타이포그래피 설정 (Typography settings)**:
본문을 어떻게 보여줄지 결정하는 값 묶음 — 글꼴, 글자 크기, 줄간격, 자간, 여백. **책의 속성이 아니라 읽는 사람의 속성**이므로 [[책]]마다 따로 갖지 않고 전역으로 하나만 존재한다. [[읽던 위치]]가 책별인 것과 대비된다.
_피할 말_: 테마(색·배경까지 포함하는 더 넓은 개념이며 이 프로젝트의 비목표), 폰트 설정(글꼴만 가리켜 범위가 좁다)

**표지 미리보기 (Cover preview)**:
Finder에서 `.epub` 파일 아이콘이 책 표지 이미지로 렌더링되는 것. **macOS가 자체 제공하는 기능이며 이 앱의 산출물이 아니다.** 이 앱에 대해서는 "깨뜨리지 않는다"는 요구사항으로만 존재한다.
_피할 말_: 썸네일 생성, 커버 추출

**뷰어 등록 (Viewer registration)**:
앱이 epub을 열 수 있다고 macOS에 선언하되, 기본 앱 자리는 가져가지 않는 상태. Finder의 "다음으로 열기" 목록에는 나타나지만 더블클릭 동작은 바꾸지 않는다.
_피할 말_: 파일 연결, 기본 앱 설정
